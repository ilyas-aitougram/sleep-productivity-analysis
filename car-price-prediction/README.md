# Car Price Prediction

## Objectif
Développer un modèle de Machine Learning capable d'estimer le prix d'une voiture à partir de plusieurs caractéristiques.

## Technologies
- Python
- Pandas
- Scikit-Learn
- Matplotlib

## Variables utilisées
- Âge du véhicule
- Kilométrage
- Puissance
- Réputation de la marque

## Résultats
Le modèle est capable d'estimer automatiquement le prix d'un véhicule à partir de nouvelles données.

## Compétences développées
- Préparation de données
- Machine Learning
- Régression linéaire
- Évaluation de modèle
