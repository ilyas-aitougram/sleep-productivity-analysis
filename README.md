# Sleep & Productivity Project

## Objectif
Analyser le lien entre sommeil, sport et productivité.

## Outils
Python, Pandas, Matplotlib

## Résultats
- 7–8h de sommeil = meilleure productivité
- Le sport améliore le sommeil
- Trop de café baisse la performance
